# STRING函数库与MEM操作函数分析 

前言：

​	C语言中经常使用string.h函数用于对字符串进行拷贝，赋值，查找等操作，以及使用mem相关函数进行内存清空，赋值等操作。面试过程中也经常询问strcpy与memcpy函数的区别是什么？本章的撰写作用旨在让阅读者明确常用的函数实现原理，防止在使用过程中出现问题，同时宏观上帮助阅读者理清相近函数的区别。



# 字符串长度 strlen，sizeof

## strlen函数

该函数用于统计字符串长度，检索到字符串中的结束符\0停止计数，并返回检索到的字符数。不包括\0.

## sizeof函数

sizeof不是函数，是一种C语言操作符，主要用来获取字符串占用的内存大小，遇到字符串中的\0不会停止。返回的结果中是占用内存的大小。

#  字符串拷贝

## 无数量限制拷贝strcpy

```c
char *strcpy(char *dest, const char *src); 
```

1. 目标地址应指向一个数据对象，且该对象有足够的控件存储源字符串的副本。
2. strcpy函数返回值类型为char* ，返回的是第一个参数的值，即一个字符的地址。
3. 第一个参数不必指向数组的开始，也可以是数组的其他位置。
4. strcpy函数是将源地址中的字符复制到目的地址，直到源文件中的**\0**为止，同时，**也将**\0**拷贝到目的地址**。
5. **使用时需要保证源地址字符串有\0结束符**，同时也需要程序员对于目的地址能否有足够的容量来存储字符串负责。

## 有数量限制拷贝strncpy，memcpy

```C
char *strncpy(char *dest, const char *src, size_t n);
```

​	将源地址字符串中的n个字符或空字符之前的字符拷贝至目标地址中(先满足哪个条件就拷贝到哪里)。因此，若源地址中字符数小于n，则拷贝整个字符串，包括结束符\0。若拷贝到了n个字符还是没有结束符，那么目的地址字符串中将没有结束符。

1. 函数返回值为char* ，指向目标字符串的起始地址
2. 若拷贝数量n大于源字符串长度，则将源字符串全部拷贝至目标空间，包括结束符\0，并且追加 `\0`，直到总共写满 n 个字节.
3. 若拷贝数量n小于源字符串长度，则将源字符串中的前n个字符拷贝直至目标空间，拷贝完成后，目标空间不会有结束符\0,需要手动将目标空间最后一个字节赋值为\0.

```c
void *memcpy(void *dest, const void *src, size_t n); 
```

​	负责从源地址赋值n个字节拷贝到目的地址，不关心内容，且拷贝过程中不进行数据转换。由于是内存层面的拷贝，函数参数使用void*类型，可以用来拷贝结构体等复合类型数据。

```c
void *memmove(void *dest, const void *src, size_t n);
```

​	memmove与memcpy函数功能相同，同时从源地址拷贝n个字节到目的地址。不同的是，memmove函数可以处理地址重叠的问题。

​	地址重叠指的是目的地址与源地址存在重叠的部分，如

```c
char arr[] = "123456";
// 把 arr[0] 开始的 3 个字节，拷贝到 arr[1] 开始的位置
// src 和 dest 重叠了！


#include <stdio.h>
#include <string.h>

int main() {
    // 测试内存重叠场景
    char arr1[] = "abcdef";
    char arr2[] = "abcdef";

    // 把前3个字符拷贝到后面一位（重叠）
    memcpy(arr1+1, arr1, 3);  
    memmove(arr2+1, arr2, 3); 

    printf("memcpy结果：%s\n", arr1); // 错乱：a a a c ef
    printf("memmove结果：%s\n", arr2); // 正确：a a b c ef
}
```

memcpy（不安全）

- 直接**从前往后拷贝**
- 重叠时会**覆盖还没读取的源数据** → 结果错乱

memmove（安全）

- 自动判断重叠情况
- **不重叠：从前往后拷贝**
- **重叠：从后往前拷贝** → 保证数据不被覆盖
- 结果永远正确




# 字符串比较

## 无数量限制比较strcmp 

​	`strcmp`函数用于比较两个字符串`s1`和`s2`。如果`s1`小于`s2`，则返回负数；如果`s1`等于`s2`，则返回零；如果`s1`大于`s2`，则返回正数。比较是基于字符的ASCII值进行的。

​	strcmp函数只会比较字符串数组中结束符\0前边的的部分

## 有数量限制比较strncmp memcmp

​	strncmp函数既可以比较到字符不同的地方，也可以只比较第三个参数指定的字符数。

​	`memcmp`函数用于比较两个内存块`buf1`和`buf2`的前`count`个字节。比较结果与`buf1`和`buf2`的对应字节进行比较。如果`buf1`小于`buf2`，则返回小于0的值；如果`buf1`等于`buf2`，则返回0；如果`buf1`大于`buf2`，则返回大于0的值。
